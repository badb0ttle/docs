博弈论 (Game Theory)

原文oi wiki:博弈论

Bash 博弈

Bash 博弈是一种简单的取石子博弈，其规则如下：

  • 初始只有一堆石子，数量为 NNN。

  • 两个玩家轮流操作，每次可以从堆中取走不超过 MMM （M≤NM \le NM≤N） 个石子（至少取走 1 个）。

  • 无法进行操作的玩家判负。

Bash 博弈的关键在于观察：当 NNN 是 M+1M+1M+1 的倍数时，先手必败；当 NNN 不是 M+1M+1M+1 的倍数时，先手可通过一次操作将剩余石子数变为 M+1M+1M+1 的倍数，从而获得必胜的策略。

Nim 博弈

Nim 博弈是博弈论中最基础、最典型的问题之一，规则为：

  • 有若干堆石子，每堆数量可以不同。

  • 两个玩家轮流操作，每次可以从任意一堆中取走任意数量的石子（至少取走 1 个）。

  • 最后无法操作的玩家判负。

Nim 的判定（尼姆和）

用符号 ⊕\oplus⊕ 表示按位异或（XOR）。设各堆数量为 a1,a2,…,ana_1,a_2,\dots,a_na1​,a2​,…,an​，定义尼姆和

S=a1⊕a2⊕⋯⊕an.S = a_1 \oplus a_2 \oplus \dots \oplus a_n. S=a1​⊕a2​⊕⋯⊕an​.

若初始 S=0S = 0S=0，则先手必败；若 S≠0S \ne 0S=0，则先手必胜。

下面给出标准的证明思路（分两步）：

  1. 必败态（S=0S=0S=0）只能转移到必胜态（S≠0S\ne 0S=0）。

  2. 必胜态（S≠0S\ne 0S=0）至少存在一种操作能转移到必败态（S=0S=0S=0）。

这两点合起来即可说明 S=0S=0S=0 时先手无法避免败局，而 S≠0S\ne 0S=0 时先手可以选择必胜策略。

证明 1：必败态转为必胜态

若当前 S=0S=0S=0，任意一次合法操作都会改变某个堆的大小，从而使得整体的异或和变为非零，因此必败态只能转为必胜态。

例如数组 [a1,a2,a3,a4][a_1,a_2,a_3,a_4][a1​,a2​,a3​,a4​] 且 a1⊕a2⊕a3⊕a4=0a_1\oplus a_2\oplus a_3\oplus a_4=0a1​⊕a2​⊕a3​⊕a4​=0。如果把 a3a_3a3​ 减小（或变为 000），原来的等式变为

a1⊕a2⊕a4=a3,a_1\oplus a_2\oplus a_4 = a_3, a1​⊕a2​⊕a4​=a3​,

当 a3a_3a3​ 发生变化时，上式不再成立，因此总异或和变为非零，证明完毕。

证明 2：必胜态可转为必败态

设当前异或和为

x=a1⊕a2⊕⋯⊕an≠0.x = a_1\oplus a_2 \oplus \dots \oplus a_n \ne 0. x=a1​⊕a2​⊕⋯⊕an​=0.

令 kkk 为 xxx 的最高位 1 的位置（从 0 位开始计）。由于该位在 xxx 中为 1，必然存在某个堆 aia_iai​ 在第 kkk 位上也为 1（否则第 kkk 位就无法被贡献为 1）。

令

b=ai⊕x.b = a_i \oplus x. b=ai​⊕x.

注意到 b<aib < a_ib<ai​（因为 xxx 在第 kkk 位为 1，异或会把该位从 1 变为 0，从而使数值变小），因此可以通过取走 ai−ba_i-bai​−b 个石子将堆 aia_iai​ 变为 bbb，这是一个合法操作。

替换后新的异或和为：

[ (a_1\oplus\dots\oplus a_i \oplus \dots \oplus a_n) \oplus a_i \oplus b = x \oplus a_i \oplus b = x \oplus a_i \oplus (a_i \oplus x) = 0. ]

因此必胜态存在至少一种操作能转为必败态，证明完毕。

实际上，这就是 Nim 判定的核心：先手需要把某一堆减小到 ai⊕xa_i \oplus xai​⊕x，从而将整体的异或和变为 0，把必败态留给对手。

(注：以上为标准 Nim 证明与说明，后续可以扩展到 SG 函数与更复杂的博弈合成规则。)

计算sg函数

一般用记忆化搜索去计算:

i64 getSG(i64 x)
{
	//一般情况下有sg(0)=0，需根据实际情况设置
	if(!x)return x;
	//记忆化搜索
	if(sg.count(x))return sg[x];
	unordered_set<ll>st;
	//将出点的sg求mex得到当前点的mex
	int d[]={1,3,4};
	for(i64 i=0;i<3;++i)
	{
		if(x-d[i]>=0)st.insert(getSG(x-d[i]));
	}
	for(i64 i=0;;++i)if(!st.count(i))return sg[x]=i;
}
